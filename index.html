Implementation of Secure File Vault

Project Overview

A Python-based Secure File Vault that protects files using AES-256-GCM encryption, SHA-256 integrity verification and PBKDF2-HMAC-SHA256 key derivation.

Features

  • AES-256-GCM file encryption
  • SHA-256 integrity verification
  • PBKDF2-HMAC-SHA256 key derivation
  • Random salt and nonce generation
  • File encryption and decryption
  • Tampering detection
  • User registration and authentication
  • Email OTP verification
  • SQLite database

Cryptographic Techniques

AES-256-GCM

AES-256-GCM is used to encrypt the actual contents of files. It provides confidentiality and authentication and detects modification of encrypted data.

SHA-256

SHA-256 generates a fingerprint of the original file. After decryption, the hash is calculated again and compared with the original hash to verify file integrity.

PBKDF2-HMAC-SHA256

PBKDF2-HMAC-SHA256 derives a secure 256-bit encryption key from the user's password using a random salt and 600,000 iterations.

Technologies Used

Python, AES-256-GCM, SHA-256, PBKDF2-HMAC-SHA256, SQLite, CustomTkinter and Cryptography.
